# Squad Tools · 本地迫击炮计算器

面向游戏 **Squad / 战术小队** 的中文 Windows 桌面软件（0.2）。内置离线地图和地形高程，独立本地计算，无需打开网页、登录账户或启动后台服务。

## 直接使用

双击 `dist/SquadTools.exe`，或解压 `SquadTools-portable.zip` 后运行其中的 `SquadTools.exe`。本机已有 .NET Framework 4.8 足够运行，**本轮没有安装任何环境或依赖**。

如果移动软件，请复制整个 `dist` 文件夹到可写目录，尤其要保留 EXE 旁的 **`maps` 文件夹**；同时保留 `README.md`、`LICENSE` 和 `third_party`。只复制 EXE 会缺少地图资源。完整便携包中的地图选择、图片显示和高差计算均可离线使用。

软件关闭时把坐标、高度、选中地图、高程模式和自定义地图边长存到软件旁的 `data/settings.xml`；导入图片存为 `data/custom-map.png`。不会修改系统设置、注册表、启动项或游戏文件。

## 已实现

- 标准部署式迫击炮的方位角、密位、水平距离、地面高差和理论飞行时间。默认高抛；仅低抛可用时明确显示低抛。
- **26 张离线地图可选**：截至本次核实的 25 张当前官方地图（23 张战斗地图，加 Jensen's Range、Pacific Proving Grounds 两张训练场），另附 Belaya Pass 旧版底图。当前范围不含模组地图。
- 选择内置地图后自动使用其真实宽高，无需手动输入尺寸；支持少数宽高不同的地图。
- 25 张当前官方地图可自动读取本地地形高程，计算炮位和目标高差；也可关闭自动模式，分别输入两处地面高度。Belaya 旧版只有底图，使用手动高差。
- 游戏网格坐标输入，例如 `D05-5-5`；支持最多三级九宫格。按最细小格中心计算。
- 本地坐标网格上选点、缩放、拖动；支持导入自己的正方形 PNG/JPEG/BMP 地图图片。
- 根据自动或手动地面高差修正弹道，另外计算 1 m 炮口偏移。
- 超出理论射程、仰角限制或无效输入时显示原因，不保留上一组可用读数。
- 窗口置顶、保存本地设置；已移除复制按钮。

## 操作步骤

1. 在“游戏地图”中选择当前对局地图，软件自动载入底图、真实尺寸和可用的地形高程。
2. 输入炮位和目标坐标。也可在地图上左键放目标、右键放炮位，或者切换工具栏标记模式。
3. 默认勾选“自动读取地形高程”。如需自行修正高度，关闭该选项后分别填写两处**地面高度**，单位米；目标更高时高差为正。手动模式中两处均为 0 表示假设地面等高。
4. 查看方位角和高抛密位。方位正北为 0°、正东为 90°；密位以 6400 为一圈。

自定义图片仍可使用：点击“导入自定义图片”，选择已裁齐实际地图四边的正方形图片，并填写完整地图的真实边长。图片左上角须对应 A01 左上角，不要包含边框、图例、空白或被截掉的地图区域。自定义图片没有高程信息，需要手动填写高度；“空白网格”也使用手动尺寸和高度。

滚轮缩放、中键拖动、“全图”复位。地图点选会吸附到三级九宫格中心（格边约 11.1 m）；粗坐标的精度由其最末级决定。绿色圈为**平地理论最大射程参考**，不包含当前高差或地形遮挡。

九宫格方向与数字小键盘一致：

```text
北
7 8 9
4 5 6
1 2 3
南
```

## 当前范围与精度

当前只支持标准部署式迫击炮和 300 m 大格，不适用于其他火炮、车载迫击炮或特殊网格的模组地图。Belaya Pass 为已退役的旧版地图，保留底图便于查阅，不计入当前 25 张官方地图。

自动高程读取地表，不包含房顶、桥面等建筑附加高度；这类位置应切换手动模式修正。软件不检测弹道中途的山体或建筑遮挡，也不含热力图、OCR、自动同步游戏地图或游戏内覆盖层。窗口置顶是普通 Windows 置顶，独占全屏游戏可能遮住它。导入自定义地图时，标定不正确会导致选点错误。

参数沿用 SquadCalc：初速 110 m/s、校准重力 9.78 m/s²、仰角 800–1580 mil、炮口偏移 1 m。飞行时间使用与仰角一致的炮口高度，因此不承诺与原网站每个显示数字逐位相同。已验证数学计算、全部底图与高程文件加载，以及桌面功能；**没有在当前游戏版本中实测命中精度**。

## 编译与验证

运行和编译使用系统已有 .NET Framework，不需要 Python、Node、浏览器或现代 .NET SDK。源码仓库跟踪地图目录与下载脚本，但 Git 忽略体积较大的 `assets/maps/images/`、`assets/maps/heights/` 和上游快照 `assets/maps/source/`。

因此，**从 GitHub 首次克隆源码后，先取得离线地图数据**：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\fetch-maps.ps1 -SourceCommit 24828d6d3081c7ce52b10ef39ec86036ebf010b5
```

此步骤需要联网，以及一个**已经存在且支持 WebP 的 Python/Pillow 环境**。脚本会优先查找本机 Codex 附带的 Python，也可通过 `-PythonPath` 指定其他已有环境；不会自行安装或下载 Python、Pillow 等运行环境。本机已验证附带的 Pillow/WebP 解码可用；这只是重新取得地图的工具，不是软件运行或普通编译的依赖。重复执行会复用已下载地图，`-Force` 可重新下载。元数据、图片格式与校验值说明见 [assets/maps/README.md](assets/maps/README.md)。

地图资源齐备后，在包含 `build.ps1` 的源码项目目录编译并验证（便携包仅包含运行文件、地图与文档）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

执行策略参数仅作用于当次 PowerShell 进程，不修改系统执行策略。构建脚本只调用现有编译器并生成项目内文件，不下载、不安装；它会检查地图资源是否齐备。输出软件位于 `dist/SquadTools.exe`，并把地图复制到 `dist/maps/`；核心、地图测试与桌面验证截图位于 `build/`。测试模式不读写用户的 `data` 设置。

详细环境盘点见 [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md)，网页与源码分析见 [docs/RESEARCH.md](docs/RESEARCH.md)。
