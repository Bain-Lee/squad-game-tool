# Squad Tools · 迫击炮与服务器列表

面向游戏 **Squad / 战术小队** 的中文 Windows x64 桌面软件（0.3.1 预览版）。迫击炮计算器内置离线地图和地形高程；新增独立服务器页面，按需联网查询、核对人数并收藏服务器。两个页面在同一窗口切换，保留炮位和目标。

## 直接使用

双击 `dist/SquadTools.exe`，或解压 `SquadTools-portable.zip` 后运行其中的 `SquadTools.exe`。需要 Windows x64 和 .NET Framework 4.8。本轮没有安装系统软件；项目内增加了已校验的 Steamworks.NET 组件，用于实验性加入入口。

如果移动软件，请复制整个 `dist` 文件夹到可写目录，保留 EXE 旁的 **`maps` 文件夹、`Steamworks.NET.dll` 和 `steam_api64.dll`**，以及 `README.md`、`LICENSE` 和 `third_party`。完整便携包中的地图选择、图片显示和高差计算均可离线使用。

软件关闭时把坐标、高度、选中地图、高程模式和自定义地图边长存到软件旁的 `data/settings.xml`；导入图片存为 `data/custom-map.png`。不会修改系统设置、注册表、启动项或游戏文件。

服务器收藏单独保存到 `data/server-favorites.xml`。普通使用不保存 EOS token、玩家标识或服务器历史快照。便携包排除本机 `data` 设置。

## 服务器列表（预览）

- 点击顶部“服务器列表”才查询 EOS；停留时每 60 秒刷新，离开时取消当前查询并暂停自动刷新。
- 支持按名称、地图、模式和 IP 搜索，按许可服 / 自定义 / Fireteam 分类，收藏与筛选服务器。
- 分别展示服务器上报人数、EOS 登记人数、可见成员计数、普通与预留排队人数。失败或无法核验显示未知，不改成 0 人。
- 默认折叠相同公网连接地址和游戏端口的记录，可取消折叠查看。占位地址、内网地址、同 IP 不同端口不会因此误合并；折叠不代表已确认哪条是原服。
- 默认在刷新后核验当前筛选结果中人数最多的前 10 台，也可单独核验所选服务器。连续显著差异会提示；“隐藏持续人数差异”需要自行勾选，规则仍需更多现场样本校准。
- “加入（实验性）”通过 Steam 大厅入口尝试连接，需要 Steam 已启动且账号拥有 Squad。已实现入口与失败提示，**尚未验证当前游戏内成功进入目标服务器**；发起请求不代表进服成功。

2026-10-25 已使用正式程序验证 EOS 列表查询及前 10 台可见成员查询；该结果不等于验证了所有服务器真实人数，也不等于识别了所有阴兵或冒牌服务器。实现、验证范围与限制详见 [docs/SERVER_BROWSER.md](docs/SERVER_BROWSER.md)。

## 迫击炮功能

- 标准部署式迫击炮的方位角、密位、水平距离、地面高差和理论飞行时间。默认高抛；仅低抛可用时明确显示低抛。
- **26 张离线地图可选**：截至本次核实的 25 张当前官方地图（23 张战斗地图，加 Jensen's Range、Pacific Proving Grounds 两张训练场），另附 Belaya Pass 旧版底图。当前范围不含模组地图。
- 选择内置地图后自动使用其真实宽高，无需手动输入尺寸；支持少数宽高不同的地图。
- 25 张当前官方地图可自动读取本地地形高程，计算炮位和目标高差；也可关闭自动模式，分别输入两处地面高度。Belaya 旧版只有底图，使用手动高差。
- 游戏网格坐标输入，例如 `D05-5-5`；支持最多三级九宫格。按最细小格中心计算。
- 本地坐标网格上选点、缩放、拖动；支持导入自己的正方形 PNG/JPEG/BMP 地图图片。
- 放大后拖动复用已有绘制图层，减少重复绘制；拖动时优先流畅，松开后恢复高质量显示。
- 根据自动或手动地面高差修正弹道，另外计算 1 m 炮口偏移。
- 超出理论射程、仰角限制或无效输入时显示原因，不保留上一组可用读数。
- 窗口置顶、保存本地设置；已移除复制按钮。

## 操作步骤

1. 在“游戏地图”中选择当前对局地图，软件自动载入底图、真实尺寸和可用的地形高程。
2. 输入炮位和目标坐标。也可在地图上左键放目标、双击右键放炮位，或者切换工具栏标记模式后使用左键放点。
3. 默认勾选“自动读取地形高程”。如需自行修正高度，关闭该选项后分别填写两处**地面高度**，单位米；目标更高时高差为正。手动模式中两处均为 0 表示假设地面等高。
4. 查看方位角和高抛密位。方位正北为 0°、正东为 90°；密位以 6400 为一圈。

自定义图片仍可使用：点击“导入自定义图片”，选择已裁齐实际地图四边的正方形图片，再在导入弹窗中填写完整地图的真实边长。图片左上角须对应 A01 左上角，不要包含边框、图例、空白或被截掉的地图区域。自定义图片没有高程信息，需要手动填写高度；“空白网格”沿用上次保存的自定义尺寸，未导入过图片时为 3000 米。底部不再显示尺寸输入框，内置地图的真实尺寸显示在地图标题下方。

按住右键移动鼠标即可拖动地图；滚轮缩放，“全图”复位，也保留中键拖动。右键单击不放置标记；双击右键在第二次松开时设置炮位，拖动过程不会误放炮位。双击使用 Windows 的时间和位置容差，轻微手抖不会移动地图。

地图点击保留实际位置，不再吸附到网格中心；输入框显示对应的三级网格作为参考，悬停可查看实际米制坐标。手动编辑网格坐标后，该点按最末级小格中心重新计算。精确点击位置会随设置保存。标记采用小圆圈与中心定位点，绿色射程边界使用明暗双描边；该圈仅为**平地理论最大射程参考**，不包含当前高差或地形遮挡。

## 当前范围与精度

当前只支持标准部署式迫击炮和 300 m 大格，不适用于其他火炮、车载迫击炮或特殊网格的模组地图。Belaya Pass 为已退役的旧版地图，保留底图便于查阅，不计入当前 25 张官方地图。

自动高程读取地表，不包含房顶、桥面等建筑附加高度；这类位置应切换手动模式修正。软件不检测弹道中途的山体或建筑遮挡，也不含热力图、OCR、自动同步游戏地图或游戏内覆盖层。窗口置顶是普通 Windows 置顶，独占全屏游戏可能遮住它。导入自定义地图时，标定不正确会导致选点错误。

参数沿用 SquadCalc：初速 110 m/s、校准重力 9.78 m/s²、仰角 800–1580 mil、炮口偏移 1 m。飞行时间使用与仰角一致的炮口高度，因此不承诺与原网站每个显示数字逐位相同。已验证数学计算、全部底图与高程文件加载，以及桌面功能；**没有在当前游戏版本中实测命中精度**。

## 编译与验证

运行和编译使用系统已有 .NET Framework，不需要 Python、Node、浏览器或现代 .NET SDK。源码仓库跟踪地图目录与下载脚本，但 Git 忽略体积较大的 `assets/maps/images/`、`assets/maps/heights/` 和上游快照 `assets/maps/source/`。

因此，**从 GitHub 首次克隆源码后，先取得离线地图数据**：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\fetch-maps.ps1 -SourceCommit 24828d6d3081c7ce52b10ef39ec86036ebf010b5
```

此步骤需要联网，以及一个**已经存在且支持 WebP 的 Python/Pillow 环境**。脚本会优先查找本机 Codex 附带的 Python，也可通过 `-PythonPath` 指定其他已有环境；不会自行安装或下载 Python、Pillow 等运行环境。本机已验证附带的 Pillow/WebP 解码可用；这只是重新取得地图的工具，不是软件运行或普通编译的依赖。重复执行只复用与来源提交及地图参数一致、校验和解码均通过的完整缓存，否则会重新下载；`-Force` 可强制重新下载。整套新资源准备完成后才替换原地图目录，下载失败保留原数据。元数据、图片格式与校验值说明见 [assets/maps/README.md](assets/maps/README.md)。

地图资源齐备后，在包含 `build.ps1` 的源码项目目录编译并验证（便携包仅包含运行文件、地图与文档）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

执行策略参数仅作用于当次 PowerShell 进程，不修改系统执行策略。构建脚本只调用现有编译器并生成项目内文件，不下载、不安装；它会检查地图资源是否齐备。输出软件位于 `dist/SquadTools.exe`，并把地图复制到 `dist/maps/`；核心、地图测试与桌面验证截图位于 `build/`。测试模式不读写用户的 `data` 设置。

修改地图下载脚本后，可单独使用已有 Python/Pillow 运行离线回归测试（将路径替换为本机已有解释器）：

```powershell
& 'C:\path\to\python.exe' -m unittest discover -s tests -p 'test_fetch_maps.py' -v
```

这些测试用临时小图片模拟下载、缓存验证和目录替换失败，不访问网络、不修改实际地图目录，也不属于普通编译的必需步骤。

详细环境盘点见 [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md)，网页与源码分析见 [docs/RESEARCH.md](docs/RESEARCH.md)，拖动优化的性能对比与验证范围见 [docs/PERFORMANCE.md](docs/PERFORMANCE.md)。

生成便携包：`powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package.ps1`。打包只使用构建产物，不包含本机设置和调试样本。普通 `build.ps1 -Test` 使用离线样本验证服务器逻辑，不联网、不初始化 Steam。
