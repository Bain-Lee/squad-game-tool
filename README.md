# Squad Tools · 本地迫击炮计算器

面向游戏 **Squad / 战术小队** 的中文 Windows 桌面首版（0.1）。独立本地计算，无需打开网页、登录账户或启动后台服务。

## 直接使用

双击 `dist/SquadTools.exe`。保留随附的 `README.md`、`LICENSE` 和 `third_party` 文件夹。本机已核实具备所需 .NET Framework 4.8，**本轮没有安装任何环境或依赖**。

如果移动软件，请复制整个 `dist` 文件夹到可写目录。也可以解压 `SquadTools-portable.zip` 后运行。软件关闭时把坐标、高度、地图边长存到软件旁的 `data/settings.xml`；导入图片存为 `data/custom-map.png`。不会修改系统设置、注册表、启动项或游戏文件。

## 已实现

- 标准部署式迫击炮的方位角、密位、水平距离、地面高差和理论飞行时间。默认高抛；仅低抛可用时明确显示低抛。
- 游戏网格坐标输入，例如 `D05-5-5`；支持最多三级九宫格。按最细小格中心计算。
- 本地坐标网格上选点、缩放、拖动；支持导入自己的正方形 PNG/JPEG/BMP 地图图片。
- 分别输入炮位、目标地面高度，自动修正高差，另外计算 1 m 炮口偏移。
- 超出理论射程、仰角限制或无效输入时显示原因，不保留上一组可用读数。
- 窗口置顶、复制诸元、保存本地设置。

## 操作步骤

1. 输入炮位和目标坐标。也可在地图上左键放目标、右键放炮位，或者切换工具栏标记模式。
2. 分别填写两处**地面高度**，单位米。两处均为 0 表示假设地面等高；软件不会据此知道真实地形。
3. 查看方位角和高抛密位。方位正北为 0°、正东为 90°；密位以 6400 为一圈。
4. 如需地图，导入已裁齐实际地图四边的正方形图片，并设置完整地图的真实边长。图片左上角须对应 A01 左上角，不要包含边框、图例、空白或被截掉的地图区域。

滚轮缩放、中键拖动、“全图”复位。地图点选会吸附到三级九宫格中心（格边约 11.1 m）；粗坐标的精度由其最末级决定。绿色圈为**平地理论最大射程参考**，不包含当前高差或地形遮挡。

九宫格方向与数字小键盘一致：

```text
北
7 8 9
4 5 6
1 2 3
南
```

## 首版范围

这是一版可运行的功能重建，尚未达到原工具的完整能力。当前只支持标准部署式迫击炮和 300 m 大格，不适用于其他火炮、车载迫击炮或特殊网格的模组地图。

没有内置游戏地图、自动高程、地形遮挡判断、热力图、OCR、自动同步游戏地图或游戏内覆盖层。窗口置顶是普通 Windows 置顶，独占全屏游戏可能遮住它。普通地图图片不含可供计算的高程；手动高差也不会检测中途山体遮挡。导入地图标定不正确会导致选点错误。

参数沿用 SquadCalc：初速 110 m/s、校准重力 9.78 m/s²、仰角 800–1580 mil、炮口偏移 1 m。飞行时间使用与仰角一致的炮口高度，因此不承诺与原网站每个显示数字逐位相同。已进行数学与桌面启动验证，**没有在当前游戏版本中实测命中精度**。

## 编译与验证

已有系统 .NET Framework C# 编译器，可在包含 `build.ps1` 的源码项目目录运行（便携包仅包含运行文件与文档）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

该参数仅作用于这一次 PowerShell 进程，不修改系统执行策略。脚本只调用现有编译器并生成项目内文件，不下载、不安装。输出软件位于 `dist/SquadTools.exe`；核心测试与桌面验证截图位于 `build/`。测试模式不读写用户的 `data` 设置。

详细环境盘点见 [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md)，网页与源码分析见 [docs/RESEARCH.md](docs/RESEARCH.md)。
