# 地图拖动性能优化

核验日期：2026-10-23。0.2.2 将地图、网格、标签、标记及固定提示拆为保留绘制层；平移时更新图层位置和裁剪，不重新生成地图与文字。鼠标移动事件按显示帧合并，拖动期间优先使用快速图片采样，结束拖动恢复高质量显示。

## 同场景前后对比

在本机现有 .NET Framework / WPF 环境中，以 Black Coast 的 4096×4096 地图、1100×760 视口、8 倍放大执行 1200 次平移更新。预热后分 5 轮、每轮 240 次记录每次更新的平均耗时，表中耗时为 5 轮的中位数。

| 指标 | 0.2.1 基线 | 0.2.2 优化后 |
| --- | ---: | ---: |
| UI 线程每次场景更新耗时 | 0.358595 ms | 0.002185 ms |
| 计时期间 Gen0 垃圾回收次数 | 28 | 0 |

这些数据只衡量 UI 线程生成绘制命令和更新变换的开销，**不包含图像光栅化、GPU 合成、显示器刷新或实际鼠标事件时序，也不是屏幕 FPS**。具体拖动手感还受显卡、驱动、显示缩放及桌面环境影响，应在实际使用窗口中确认。

优化前后均使用相同地图、视口和放大倍数，未缩小原始地图或降低保存资源的质量。独立基准程序位于 `tests/RenderBenchmark.cs`；本次基线和优化后原始结果保存在未纳入 Git 的 `build/render-before.txt`、`build/render-after.txt`。

运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Benchmark` 可取得当前实现的同场景结果；不同运行间数值会有波动。旧绘制器基线来自提交 `0a41042` 的 `src/MapView.cs`，可与同一基准程序单独编译对照。

## 交互边界

实现保留小标记、高对比度射程圈、矩形地图尺寸及精确点击。放大时以光标所在位置为锚点，拖动结束、鼠标捕获丢失和视图复位会提交最后位置并清理逐帧订阅。测试与桌面检查另验证地图切换、精确点保存、自动高程、视图缩放和原有计算行为。

底部地图边长输入框已删除。内置地图继续使用其元数据尺寸；自定义图片仅在导入时标定实际边长，旧设置中的 `mapSize` 值仍可读取。
