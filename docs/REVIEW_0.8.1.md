# 0.8.1 交互、主题与服务器延迟审查

审查范围为滑轨按下后连续拖动、当前主题图标、浅色地图背景、暖米白配色、服务器延迟排序和固定筛选表头。

- 滑轨首次按下由应用接管，避免 WPF 内置 `IsMoveToPointEnabled` 类事件先消费输入；保持按下时跟随鼠标，松开、失去捕获或关闭弹层时结束。滑块本身继续使用原有拖动逻辑。
- 太阳对应当前浅色，月亮对应当前深色。地图画布与 HUD 使用可更新画刷，已有地图缓存随主题换色；游戏图片、点位和弹道参数不变。
- 延迟是本机到服务器 IP 的 ICMP RTT，失败和超时保留未知。默认升序、点击反转，未知始终置底。表头箭头反映实际排序；筛选、刷新、收藏及测量更新保留排序和选择。
- 延迟测量有 IP 去重、60 秒缓存、8 个并发与 1 秒超时。退出旧轮次后不发布旧回调；仍在排空的原生请求继续占用并发名额。列表刷新失败会使过期读数变为未知，未测量地址优先，避免大列表饿死。
- 筛选表头使用固定行与独立展开内容，展开前后位置不变；人数自动核验继续按人数最多的前 10 台执行。

## 验证

`build.ps1 -Test` 完整通过，编译无警告，共 21,630 项断言：核心 2,624、地图 211、绘制/交互 704、服务器模型 119、延迟后端 39、服务器界面 61、武器与同步 718、RAAS 12,102、布局 922、前版功能 3,945、高差基准 CR 24、外观 161。正式程序射击页与模拟服务器页启动检查通过。

真实鼠标检查从滑轨非滑块位置按下并持续移动，最终读数跟随至 78%，再次从另一滑轨位置拖至 100%；不是仅验证对滑块本身的拖动。已查看浅色射击与服务器截图，确认轻微米色、浅色地图周边、太阳图标和延迟列升序箭头。模拟测试检查两个排序方向的未知值置底、排序/选择保留、过期结果清除、取消后原生请求并发名额保留及筛选表头位置稳定。

2026-10-30 另做真实网络小样本检查：EOS 返回 567 条记录，对其中 3 个公开 IP 各测一次 ICMP，得到 45 ms、183 ms 和 1 个未知。未知没有改写为 0。该结果仅证明本机当时的列表与 ICMP 测量路径可用，不等于测量全部服务器，也不等于游戏内延迟或人数验证。
