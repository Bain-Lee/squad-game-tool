# 服务器工具代码审查与修复

审查范围：服务器列表预览版提交 `8f53682`，包括数据解析、人数判定、WPF 页面状态、收藏保存、Steam 辅助进程，以及接入主窗口和构建流程的改动。修复版本为 0.3.1 预览版。

## 已修复问题

| 级别 | 触发条件与原行为 | 修复与回归验证 |
| --- | --- | --- |
| P2 | 上报人数改变后只清除界面标记，旧差异样本仍在历史中，下一次核验可能立即重新隐藏服务器。缺少上报人数也会显示“未见明显差异”。 | 刷新和证据计算都校验人数是否改变；中途关闭自动核验也清除旧样本。缺字段显示“无法比较”。模型与页面回归覆盖。 |
| P2 | 持续网络失败时不再执行筛选，超过 180 秒的核验结果和隐藏状态可能无限期保留。 | 页面每秒检查过期状态，独立于请求成败；过期后清空可见人数与隐藏标记。模拟断网验证服务器重新出现。 |
| P2 | 收藏 XML 损坏时加载失败，但下一次收藏会用空内存集合覆盖原文件。 | 读取失败或根节点错误时暂停写入；独立临时文件原子替换，失败后清理临时文件。验证损坏文件字节不变和正常增删收藏。 |
| P2 | 关闭窗口或切页不会取消正在准备的加入辅助进程，可能稍后才唤起游戏；冷却从点击开始，早于入口实际创建时间。按钮到期也不会主动恢复。 | 准备操作可取消，辅助进程取消不依赖窗口继续处理消息；成功后才开始 90 秒冷却。模拟真实子进程验证取消、超时、错误、成功后保留入口；页面测试验证冷却和关闭。 |
| P2 | 查询未结束时迅速离开再返回，旧查询已取消，但因 busy 状态跳过新查询，空列表可能等待整整一个刷新周期。 | 记录待恢复刷新，在取消结束且 10 秒限频到期后重试。模拟延迟响应验证旧结果丢弃、新查询恢复。 |
| P2 | 刷新、核验或收藏重新设置列表后丢失用户列排序。 | 恢复排序描述、排序箭头和所选 Session；页面回归验证实际行顺序。 |
| P2 | 缺失或无效的更新时间回退为本次查询时刻，折叠同入口或合并同会话时可能压过有可信时间的记录。 | 无效及未来时间视为未知，不参与“最新”优先；覆盖不同会话和同会话的重复结果。 |

同时统一版本号解析与加入辅助进程的参数要求，拒绝非 ASCII 数字和过长 build ID。

## 验证边界

- 服务器模型、HTTP 协议及辅助进程测试为 120 项断言；新增 WPF 页面回归为 36 项断言。
