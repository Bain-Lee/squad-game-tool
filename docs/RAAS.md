# 全原版地图 RAAS 猜点（0.5.0）

数据快照与验证日期：2026-10-25。范围为当前内置的 23 张官方战斗地图、39 个 RAAS 图层，不限定 Goose Bay。两张训练图没有 RAAS；旧版 Belaya 已退役，其图层请求返回 404，目录中单独标记。模组地图不在本轮数据范围。

## 操作

1. 点击顶部“RAAS 猜点”。选择地图及具体 RAAS 图层，例如 Gorodok RAAS v1 或 Sanxian RAAS v3 CL。
2. 通过下拉框或地图上的 1/2 基地标记，选择己方主基地，确定从哪一端计数。
3. 点击下一旗候选标记进行确认；也可从左侧候选列表选择，点“确认所选点”或按 Enter。每次只确认当前下一顺位，程序重新收敛路线与候选点。
4. “上一步”撤销末点；“重置”清除旗点链，保留己方视角。点击已确认的点会退回到该点之前；切换主基地清除原方向的确认。
5. 默认显示当前下一旗。“显示后续可能点”可展示更远的可能顺位；当前下一旗标为绿色，已确认标为浅色，后续候选为蓝色。标记重叠时可缩放地图或从左侧列表选择，悬停查看点名和顺位。

猜点模式仍可右键拖动、中键拖动、滚轮缩放和“全图”复位。左键确认旗点以及右键双击不会移动射击炮位或目标；切回“射击计算”恢复原地图操作。猜点链在当前进程内保留，不自动跨重启恢复。

## 服务器与图层切换

服务器列表已经保存完整 EOS 地图字段，例如 `GooseBay_RAAS_v2`。选择服务器后可进入猜点页使用对应图层；已处于猜点页时再选择服务器，会回到猜点页。

基础地图改变时，更换底图与高程并重置旧点位。基础地图相同但图层改变时，仅重置猜点状态；相同图层的服务器刷新不会清除已确认旗点。AAS、Invasion 或未收录的服务器图层不会被偷偷替换为本图 RAAS v1；页面会提示，可手动选择其他 RAAS 图层。手动选择地图或图层会停止服务器地图跟随。

## 数据与算法

数据来自 SquadCalc 的公开图层接口：`/api/get/layers?map=<地图名>` 和 `/api/get/layer?name=<完整图层名>`。本轮按 26 张内置底图逐个查询，39 个 RAAS 图层全部获取并归一化到 `assets/layers/`。每层保存主基地、候选 ID、点簇、坐标及有向链接，不保存无关的载具/工事资产。

底图原点固定到 SquadCalc 源码 `24828d6d3081c7ce52b10ef39ec86036ebf010b5` 的 SDK minimap 标定。候选坐标由 SDK 厘米转换成现有地图米制坐标；运行时校验图层与底图来源版本一致。`layers` 目录随便携包分发，正常逐点计算不联网。

`RaasSolver` 按点簇链接枚举主基地间的路线。已确认点与顺位形成约束，剔除不相容路线。剩余路线等权，每个顺位的候选在点簇内等分权重；相同物理地点的多个候选 ID 合并显示。使用唯一 ID 区分不同地点，不能只按显示名称合并。

这是上游模型下的概率估计，未根据真实对局随机分布做校准；某点标为 100% 也只是“在当前数据和已确认条件下只剩这一候选”。遇到冲突点、循环、缺链接或超过 2000 条路线时不继续展示不完整概率。游戏更新后可能需要刷新数据，本版没有读取游戏隐藏状态或实际运行中的随机种子。

## 验证

39 个图层均由 C# 运行时解析；两个主基地方向均完成整条旗点链，检查每一步概率归一化、确认、撤销、重置和坐标范围。测试还将 234 个状态的路线数、候选 ID 与概率逐项对照固定源码的上游原始求解器。

WPF 回归逐个通过真实地图/图层选择器加载 39 层，并验证地图旗点点击、射击输入隔离、同图不同层的服务器切换、同层刷新保留选择、非 RAAS/未知地图明确提示、Enter 确认及模式往返。RAAS 测试共 12029 项断言，逐层报告见 [RAAS_COVERAGE.md](RAAS_COVERAGE.md)。测试使用离线数据，不替代当前游戏版本中的实际对局验证。
