# 简约界面（0.7.0）

本轮统一分段导航、留白、圆角和低饱和蓝色强调，减少常驻的重复说明。

- 射击页：炮位、目标坐标及高程始终显示，左侧卡片与整个地图框等高；内部内容靠上紧凑排列，方位与仰角紧跟输入区。有地形数据时自动读取并显示高程，不再保留开关；无数据地图可手动填写。旧版关闭自动高程的设置不再影响自动采样。仅在存在多种弹药时显示弹药选项。正常窗口全部输入无需滚动，紧凑窗口保留可见的解算结果和 6 像素细滚动条。RAAS 卡片继续使用完整高度。
- 服务器页：详情改为无滚动条的摘要卡，区分上报、EOS 登记、可见成员和排队。完整名称、IPv6 地址、公开容量、版本、核验时间保留在“详情 ⓘ”悬停提示。低频筛选折叠到“更多筛选”，行为和默认值不变。
- RAAS 页：突出当前下一旗，完整确认链、剩余路线、数据日期放到悬停提示；异常仍显示原因，长提示收敛在两行内。

0.7.0 在结果区上方加入“自动 / 高抛 / 低抛”选择；散布、伤害圈与“弹道剖面”放在地图底栏。剖面是可独立关闭的详情窗，默认按当前弹道缩放，勾选后才把高低抛同时放入图中，避免高抛顶点压缩低抛附近的地形细节。RAAS 的后续候选与自动补齐选项并排显示，最小窗口和长提示下仍保留可用的候选区。

## 审查与验证

0.6.2 的布局审查未修改弹道参数、EOS 查询、人数核验和 RAAS 求解算法。0.7.0 继续沿用原有射击求解与 RAAS 路线权重，补充弹药散布/伤害元数据及围绕求解结果的选择、预览、自动推进和绘制。

`build.ps1 -Test` 包含原有回归及 `LayoutTests`。布局测试使用真实 WPF 窗口，覆盖 1060×740、1280×850、1440×900，全部九种武器、高程常驻、自动采样及无数据回退、左右卡片等高、多弹药、无效坐标清除旧高程、细滚动条分页、长服务器名称、IPv6、缺失人数与展开筛选。设置回归另外验证旧版关闭自动高程的配置可以迁移。截图输出到 `build/layout-*.png`；测试使用模拟服务器数据，不联网、不写入用户设置。

便携包继续保留 `maps`、`layers`、文档和许可，排除用户 `data` 与调试资料。没有安装运行环境或修改系统滚动条设置。
