# 简约界面（0.8.0）

本版保留分段导航、卡片、圆角和低饱和蓝色强调，减少常驻的重复说明，并提供游戏时可调的窗口外观。

## 顶部图标与外观

右上角从左到右为透明度、置顶、浅深色主题、帮助。按钮使用统一的线条图标，提供悬停用途提示、键盘焦点和选中状态；删除原来的“离线可用”徽标。

点击透明度图标，在按钮下方打开滑条。范围为 30%–100% 的窗口不透明度，拖动时立即预览主窗口与已打开的弹道详情窗；低端仍保留可见窗口便于恢复。点击外部、再次点击按钮、按 Escape 或切换至其他窗口可收起浮层。置顶使用普通 Windows 窗口置顶，独占全屏游戏可能遮住它；透明度不提供点击穿透。

浅深色切换覆盖射击、RAAS、服务器列表/详情、下拉菜单、提示框、导入标定窗口及弹道剖面。地图和阵营图片保持原素材颜色。关闭时保存窗口不透明度、主题和置顶偏好，重新打开时恢复。

## 页面显示

- 射击页：保留炮位、目标坐标，结果区只显示高度差，隐藏两个具体高程。有地形数据时始终自动读取；无数据地图显示一个“地面高差”输入框，正值表示目标更高、负值表示更低，0 表示地面等高。旧版两个手动高度按“目标减炮位”迁移，旧版关闭自动采样的设置不再影响自动读取。内部 SDK 高程及弹道计算保持原值。
- 布局：左侧卡片与整个地图框等高，内容靠上紧凑排列，方位与仰角紧跟输入区。只在有多种弹药时显示弹药选项。正常窗口无需滚动，紧凑窗口保留结果区和 6 像素细滚动条。射击与 RAAS 标题下的小字、原高程说明、正常解算状态及“尚未确认”闲置提示已清理；无效输入、无可用解和缺失图层等错误继续显示。
- 弹道详情：默认只绘制当前弹道，勾选后同时比较高低抛；纵轴和悬停值以炮位地面为 0。沿程地形未知时明确标注，不生成虚假平地，也不执行自动遮挡判定。详情随当前输入、主题和不透明度更新。
- RAAS 页：突出当前下一旗和候选概率，保留有效确认链、自动补齐及悬停预览。默认手动/阵营说明和概率说明页脚不常驻；概率模型说明保留在候选列表悬停提示。错误继续显示。
- 服务器页：详情使用无滚动条摘要卡，区分上报、EOS 登记、可见成员和排队。完整名称、IPv6 地址、公开容量、版本和核验时间保留在“详情 ⓘ”悬停提示，低频筛选收入“更多筛选”。

## 审查与验证

本版沿用已有弹道参数、EOS 查询、人数核验及 RAAS 路线求解，主要调整显示、外观设置和旧设置兼容。手动高差输入避免在每次按键后重新格式化正在编辑的文本，保留负号、小数点及原有小数精度。

`build.ps1 -Test` 执行原有回归、布局检查及本版外观专项测试。覆盖三种窗口尺寸、全部九种武器、自动高差和无地形手动回退、左右卡片等高、多弹药、无效输入清除旧读数、细滚动条分页、长服务器名称、IPv6 和缺失人数。外观专项检查图标顺序、透明度实时更新与恢复、浅深色切换、详情窗联动、旧高度迁移和小数编辑。

测试使用离线地图及模拟服务器，设置写入独立临时目录。原生窗口检查和截图保留于 `build/`；本轮最终结果见 [0.8.0 代码审查](CODE_REVIEW_2026-10-30.md)。这些检查不代表游戏内命中精度或游戏窗口兼容性验证。

便携包继续保留 `maps`、`layers`、文档和许可，排除用户 `data` 与调试资料。没有安装运行环境或修改系统滚动条设置。
