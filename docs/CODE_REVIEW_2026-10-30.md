# 0.8.0 界面、透明度与主题代码审查

审查日期：2026-10-30。范围为高差显示、相对高度剖面、右上角图标、透明度预览、浅深色主题、设置迁移和对应回归。

## 审查与修正

- 内置地图仍按原 SDK 世界 Z 采样，实际解算继续使用目标减炮位的高差。主界面隐藏具体高程，剖面轴值和悬停值在显示时减去炮位地面高度；未对负数取绝对值或截断，也未修改弹道参数。
- 缺失地形数据时使用单个带符号的手动高差。旧两个高度按差值迁移，新外观字段缺失时采用默认值；无效或非有限透明度不应用，合法值限制在 30%–100%。
- 修正手动高差逐键输入时的重入格式化：输入 `12.3` 的中间文本 `12.` 不再被立即改写为 `12`，避免后续输入变成 `123`。负号、小数和高精度文本可持续编辑，临时无效输入清空解算结果，恢复后重新计算。
- 透明度滑条同步更新主窗口及详情窗；浮层可由外部点击、Escape、再次点击按钮和窗口失活收起。主题画刷通过绑定保持可更新，避免 WPF 模板冻结共享画刷后无法切换；新打开的下拉菜单、服务器行和详情也使用当前主题。
- 原生检查发现标准 WPF 窗口只设置 `Window.Opacity` 会降低内容不透明度，但原生窗口背景仍遮挡下方画面。现保持内容不透明，通过 Windows 的 `WS_EX_LAYERED` 与 `LWA_ALPHA` 调整整个窗口；有限范围的样式消息钩子避免 WPF 移除透明标志，并保留置顶等其他样式。默认 100% 不透明时不额外启用该机制。
- 真实鼠标操作修正了再次点击透明度图标时浮层关闭后立即重开的时序问题。浮层改由按钮及明确的外部点击、Escape、失活事件控制；连续拖动不会收起滑条。
- 删除顶部离线徽标、页面标题下说明、具体高程说明、正常解算闲置小字及 RAAS 未确认占位提示；保留输入错误、不可用解、缺失图层和必要的跟随异常提示。
